# rag-guard

Guarded RAG: a pure-stdlib, zero-runtime-dependency pipeline that refuses to answer when retrieval finds no support, checks answers against retrieved context for groundedness, and redacts PII from output — with a trace on every step and an eval harness that scores it.

- **Status:** active, public repo with CI/CodeQL/coverage badges, published to PyPI as `guarded-rag`
- **Entry points:** `rag_guard/` (import name; PyPI package name is `guarded-rag`), `eval/`, `ops/`, `bin/`, `docs/`
- **Run/test:** `pip install guarded-rag`; see README Quickstart for pipeline usage
- **Two index backends:** `sqlite_index.py` (inverted, DEFAULT — ~0.35s cold hook) and `index.py` (JSON forward vectors, ~3.9s). Identical rankings; `RAG_GUARD_BACKEND=json` rolls back. Rebuild is global and costs ~13-15s, but **serve-stale is ON by default**: a stale index is served immediately and a detached `rag_guard.reindex --backends sqlite` refreshes it (lock at `<cache>.rebuild.lock`, one at a time, 300s steal). `RAG_GUARD_SERVE_STALE=0` restores blocking. The detached child records ok/fail to `<cache>.rebuild.json` (`rebuild_health.py`) because its stderr is DEVNULL — **serving stale is only defensible while staleness is bounded and observable**, so the hook appends a one-line warning after 2 consecutive failures or 6h without a successful rebuild. **reindex must NEVER unlink the cache first** — that opened a 20s window where a hook found no index to serve.
- **HOOK ISOLATION (do not weaken):** `bin/hook_userpromptsubmit.py` grounds ONLY on interactive entrypoints (`cli`/`vscode`/`jetbrains`); `claude -p` reports `sdk-cli` and gets silence. This once contaminated a published experiment (535 verdicts re-judged). The injection decision fails CLOSED; error handling stays fail-open. Opt back in only via `RAG_GUARD_ALLOW_HEADLESS=1`.
- **Provenance:** chunk ids are qualified by corpus root (`Hunt-621-Wiki/Note.md#3`), relative to the root's PARENT (`corpus._add_file`). `index.CORPUS_SCHEMA` is in the fingerprint — **bump it whenever id or chunk-text shape changes**, or stale caches keep serving the old format.
- **Hook instrumentation:** `hooklog.py` records every hook decision (fires AND silent ones, with reason) to `~/.local/state/rag-guard/hook-fires.jsonl`, 0600, opt-in via `RAG_GUARD_HOOK_LOG=1` (live in settings.json). Analyze with `PYTHONPATH=. python3 bin/hook_report.py` — joins fires to session transcripts by `session_id`. Exists so gate changes (MIN_SCORE / HOOK_MIN_OVERLAP) are made on data, not intuition.
- **Constraints:** bring-your-own-model, no runtime deps; also powers a UserPromptSubmit hook wired into `~/.claude/settings.json`; one layer of the "cost-governance stack" with bow/fleet-mode/agent-gate/agent-cost-attribution/oracle-gate
